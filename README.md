# System Tools for LG webOS

All-in-one system management suite for LG webOS TVs.

## Features

- **Task Manager**: Interactive process viewer displaying active PIDs, app names, and per-process RSS memory consumption.
- **Individual Process Kill**: Terminate misbehaving or background applications with D-pad navigation.
- **Live Memory Gauges**: Real-time total, available, and consumed RAM bar with warning threshold indicators.
- **Free Memory Cleaner**: 1-click RAM cache flusher that drops system caches and reports reclaimed memory with a TV toast notification.
- **Companion Launcher Tile**: Also installs the standalone "Free Memory" tile on your home ribbon for instant memory cleanup without opening a full UI.

## Installation

Download the latest `.ipk` from GitHub Releases or install directly through the webOS Homebrew Channel repository (`repo.webosbrew.org`).
